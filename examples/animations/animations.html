OwnFrame / examples

CSS Animation Showcase

Every card is a CSS declaration. The page registers no tick callback, builds no player, and imports no internal package: OwnFrame binds each keyframe at redraw and samples it from the window tick.

Timing

Same distance, different easing curves.

ease

ease

animation-timing-function

animation-timing-function: ease;

Expect Moves right, accelerating then slowing into the turn, then returns. The start and stop are soft.

linear

linear

animation-timing-function

animation-timing-function: linear;

Expect Moves at a constant speed to the right, then back. No acceleration or easing.

bezier

overshoot

animation-timing-function

animation-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55);

Expect Overshoots past 180px, then settles back. The bounce comes from the negative and above-one control points.

steps

stepped

animation-timing-function

animation-timing-function: steps(5, jump-end);

Expect Moves in five equal jumps, not a slide. The chip holds each position until the next step.

+0.8s

Expect Holds the start pose for 0.8s, then moves. The pause before motion is the delay.

-1s

Expect Starts already 1s into the two-second cycle, so the first visible frame is mid-path.

Expect Runs once, then snaps back to the start pose and start colour. Nothing is held.

Expect Runs once and keeps the final position and colour.

both

animation-fill-mode

Perspective

The camera animates while the chip stays still.

camera

camera pull

perspective

perspective: 320px;

Expect The camera pulls from 320px to 920px. The tilted chip looks strongly foreshortened, then flatter; the chip itself does not move.

origin

origin slide

perspective-origin

perspective-origin: left top;

Expect The vanishing point slides from top-left to bottom-right. The same tilted chip projects from a different corner.

Expect The beveled fill cycles from blue to orange. The dark border and the cut corner keep their shape.
