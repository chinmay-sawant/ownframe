OwnFrame / examples

CSS Animation Showcase

Each card demonstrates a CSS animation. Delays and one-shot runs start when this page opens; scrolling does not restart them. Loops keep running offscreen. Pause all freezes every card. Each card's Play button restarts just that animation and pauses the others.

Timing

Same distance, different easing curves.

ease

ease

animation-timing-function

animation-timing-function: ease;

Expect Moves 180px right and back with a soft start and finish. Blue, orange, and green mark the keyframe positions.

linear

linear

animation-timing-function

animation-timing-function: linear;

Expect Moves 180px right and back at constant speed. The colour follows the same keyframes as ease.

bezier

overshoot

animation-timing-function

animation-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55);

Expect Pulls back and overshoots around the keyframe positions, then reverses. The negative and above-one curve values create the bounce.

steps

stepped

animation-timing-function

animation-timing-function: steps(5, jump-end);

Expect Moves in five equal jumps per pass, holding each position until the next step, then reverses.

Delay and fill

When playback starts, and what it keeps when it ends.

+0.8s

positive delay

animation-delay

animation-delay: 0.8s;

Expect Waits once for 0.8s after the page opens at 30 percent opacity, then moves and brightens. Scrolling does not restart the delay.

-1s

negative delay

animation-delay

animation-delay: -1s;

Expect Starts 1s into its two-second pass, halfway along the path at full opacity. It then moves and fades in alternating directions.

none

animation-fill-mode

animation-fill-mode: none;

Expect Waits grey for 0.4s, makes one purple-to-green pass, then returns to the left and grey. No keyframe pose is held.

forwards

fill: forwards

animation-fill-mode

animation-fill-mode: forwards;

Expect Waits grey for 0.4s, runs once for 2.2s, then holds the right-hand position and green colour.

both

fill: both

animation-fill-mode

animation-fill-mode: both;

Expect Shows the purple start pose during the 0.4s delay, then holds the green final pose after the 2.2s run.

2D transforms

The operation matrix moves, rotates, scales, skews, and shears.

translate

translate

transform

transform: translateX(150px);

Expect Moves 150px right over three seconds, then snaps back to the start. Its size and angle stay fixed.

rotate

rotate

transform

transform: rotate(150deg);

Expect Turns 150 degrees clockwise around its centre over three seconds, then snaps back to zero.

scale

scale

transform

transform: scale(1.22);

Expect Grows from 0.72 to 1.22 over three seconds, then restarts small. The label scales with the chip.

skew

skew

transform

transform: skewX(22deg);

Expect Shears by 22 degrees: the top edge moves left and the bottom edge moves right, then the chip resets.

matrix

matrix

transform

transform: matrix(1, 0.18, -0.18, 1, 64, 0);

Expect Slides 64px right, rotates clockwise about 10 degrees, and grows slightly, then resets. One matrix combines these changes.

Perspective

The camera animates while the chip stays still.

camera

camera pull

perspective

perspective: 320px;

Expect The camera pulls from 320px to 920px. The tilted chip looks strongly foreshortened, then flatter; the chip itself does not move.

origin

origin slide

perspective-origin

perspective-origin: left top;

Expect The vanishing point slides from top-left to bottom-right. The same tilted chip projects from a different corner.

Path and alias

A corner path recolours as a fill, and the vendor keyframes resolve to the same driver.

corner

corner fill

background-color on corner-shape: bevel

corner-shape: bevel;

Expect The beveled fill cycles from blue to orange. The dark border and the cut corner keep their shape.

alias

vendor alias

-webkit-animation / @-webkit-keyframes

-webkit-animation: kf-webkit-hop 1.4s ease-in-out infinite alternate both;

Expect Rises 10px and turns from purple to pink, then returns down and purple. Alternate playback reverses this sequence; the prefix uses the same animation driver.
