# Production-readiness planning archive

This directory preserves the proposals and review notes that preceded the current API wrap. Its earlier blanket closure claim was unreliable: it mixed alias and wrapper designs, deferred work, and outdated CI descriptions.

Use [the current maintenance ledger](../../README.md) for status and evidence. The field files remain available for rationale and existing links. Their `[s]` rows are superseded proposals or assertions, not shipped-feature claims; `[-]` rows record explicit deferrals.

The library remains in the v0.0.3 development cycle. These records do not declare a v1 release.
