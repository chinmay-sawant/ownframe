# ECharts

HTML and CSS charts in the ECharts series list. Append `Stylesheet` to the page theme.

Constructors: `Bar`, `Line`, `Scatter`, `Pie`, `Radar`, `Heatmap`, `Candlestick`, `Boxplot`, `Gauge`, `Funnel`, `EffectScatter`, `PictorialBar`, `Map`, `Tree`, `Treemap`, `Graph`, `Chord`, `Parallel`, `Sankey`, `Lines`, `ThemeRiver`, `Sunburst`, `Custom`.

`Map` is a labeled region grid, not a geographic map.
